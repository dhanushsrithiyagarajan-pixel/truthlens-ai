# TruthLens AI — Mandatory Automation Documentation
## Suspicious Claim to Verification Checklist Tool
**Module Identifier:** Module I  
**File Implementation:** `backend/automation.py`, `static/js/automation.js`, `app.py`  
**API Endpoint:** `POST /api/automation/claim-to-checklist`  

---

### 1. Architectural Purpose
The primary objective of this automation is to bridge the gap between unstructured, viral social media text and structured, academic verification. When an untrained user encounters a suspicious headline or forwarded WhatsApp message, they often do not know which specific questions to ask or where to begin their investigation.

This automation ingests any raw claim, programmatically parses its semantic and entity components, maps it to a known threat vector, and synthesizes an actionable 10-step verification protocol equipped with targeted Boolean search queries and primary source repositories.

---

### 2. End-to-End Operational Pipeline

```
[ User Inputs Suspicious Claim & Source ]
                   ↓
[ 1. Entity Extraction & Sentence Decomposition ]
   - Extracts primary subject, actions, numerical figures, and organizations
                   ↓
[ 2. Issue & Threat Vector Categorization ]
   - Finance / Banking
   - Cybersecurity / Phishing
   - Health / Medicine
   - Politics / Government
   - Multimedia / Deepfake
                   ↓
[ 3. Dynamic Protocol & Query Synthesis ]
   - Formulates tailored Boolean search queries
   - Assigns category-specific primary registries (e.g. RBI, WHO, CTRI, PIB)
                   ↓
[ 4. SQLite State Persistence ]
   - Inserts record into 'checklists' table
                   ↓
[ 5. Interactive Dossier UI Transition ]
   - Loads custom steps into Interactive Dossier view with live note-taking and export
```

### 3. API Specification

#### Request
- **Method:** `POST`
- **Route:** `/api/automation/claim-to-checklist`
- **Headers:** `Content-Type: application/json`
- **Payload:**
```json
{
  "claim": "RBI issues alert warning that linking Aadhaar to PAN on third-party links will drain bank accounts.",
  "category": "finance",
  "source_url": "https://rbi-notice-alert.top/pan-link-warning"
}
```

  "status": "success",

### 4. Fallback Logic & Anti-Hallucination Integrity
When no external generative LLM API key (`GEMINI_API_KEY`) is configured, the system executes transparent, deterministic rule-based heuristic logic (`backend/automation.py`). It clearly labels the output:
> *"Automated 10-step verification protocol generated by TruthLens AI Automation Engine."*

The engine does not pretend that an external AI service was consulted when running in local offline mode, fully complying with the project's academic integrity standards.
